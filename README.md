# 🎮 Hangman Game – Python

A simple **command-line Hangman game built using Python** as part of the **CodeAlpha Internship Project**.

The player has to guess the hidden word one letter at a time. The game provides a maximum of **6 incorrect attempts** and includes input validation, duplicate-guess prevention, and an option to play multiple rounds.

## 📌 Features

- 🎯 Randomly selects a word from a predefined word list
- 🔤 Allows the player to guess one letter at a time
- ❤️ Maximum of **6 incorrect attempts**
- ✅ Displays correctly guessed letters
- 🔲 Shows underscores for letters that haven't been guessed
- 🚫 Prevents duplicate guesses
- ⚠️ Validates user input
- 🔄 Option to play multiple rounds
- 🖥️ Simple and user-friendly command-line interface

## 🛠️ Technologies Used

- **Python 3**
- **Random module**
- Python Sets
- Functions
- Loops and Conditional Statements
- User Input Validation
